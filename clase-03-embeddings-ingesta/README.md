# Clase 3 — Embeddings e ingesta documental

## Contenido de esta carpeta

- `clase-03.ipynb`: notebook de la clase (teoría, demos ejecutables y laboratorio).
- `dataset_evaluacion_generado.json` (se crea al correr la sección 12): dataset de evaluación generado automáticamente, que se usa en la Clase 6.
- `requirements.txt`: dependencias para correr el notebook.
- Guía para el docente: [`docente/clase-03-embeddings-ingesta/guia-docente.md`](../docente/clase-03-embeddings-ingesta/guia-docente.md).

## Cómo correr el notebook

Desde la raíz del repo (donde está el `.env` con tus credenciales, ver `.env.example`):

```bash
pip install -r clase-03-embeddings-ingesta/requirements.txt
jupyter notebook clase-03-embeddings-ingesta/clase-03.ipynb
```
